# DocFlow AI Admin Manual

This document explains how Super Admin and Organization Admin manage the system.

---

## 1. Admin Roles

### Super Admin

Super Admin controls platform-level data.

Super Admin can:

- View all organizations
- Activate/deactivate organizations
- View platform users
- View all requests
- View audit logs
- View platform reports

### Organization Admin

Organization Admin controls organization-level data.

Organization Admin can:

- Manage departments
- Manage users
- Manage workflows
- Manage approval policies
- View organization requests
- View reports
- View audit logs
- Manage delegation
- Configure organization settings

---

## 2. Super Admin Dashboard

Super Admin dashboard shows:

- Total organizations
- Active organizations
- Inactive organizations
- Total users
- Organization admins
- Total departments
- Total requests
- Pending requests
- Approved requests
- Recent users
- Recent organizations
- Recent audit logs
