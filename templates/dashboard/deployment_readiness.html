Before Going Live

Final sanity checks, because hope is not an architecture.

  • Take a full backup.
  • Test login/logout.
  • Test upload and approval flow.
  • Test SMTP email.
  • Test Celery worker and Beat.
  • Check system health dashboard.
  • Disable maintenance mode.
  • Confirm HTTPS works.
Recommended Production Stack
  • Nginx reverse proxy with HTTPS.
  • Gunicorn or Daphne depending on sync/ASGI needs.
  • PostgreSQL database.
  • Redis for Celery and cache/session if configured.
  • Celery worker and Celery Beat as separate services.
  • Scheduled backups enabled.
  • SMTP configured with app password.
