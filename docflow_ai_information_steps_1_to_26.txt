HOW TO USE THIS FILE
================================================================================
How to use this reference:
1. Start a new chat or continue the same project.
2. Copy one prompt, for example: Start Step 26 - Create secure share link module...
3. Ask for required files one by one, for example: models.py, forms.py, views.py, urls.py, admin.py, templates, CSS.
4. After each step, run:
   python manage.py makemigrations
   python manage.py migrate
   python manage.py check
   python manage.py runserver
5. Keep this file as your master roadmap for DocFlow AI.
